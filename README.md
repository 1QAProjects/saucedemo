# Selenium Automation Framework

A robust Selenium Automation Framework built using Java, Maven, JUnit 5, and Page Object Model (POM).

## Features

- Selenium WebDriver
- Java
- JUnit 5
- Page Object Model (POM)
- WebDriverManager
- Log4j2 Logging
- Allure Reporting
- Screenshot Capture on Failure
- Maven Build
- Git & GitHub Integration

## Project Structure

```
src
 ├── main
 └── test
      ├── base
      ├── pages
      ├── tests
      ├── utils
      └── extensions
```

## Technologies Used

- Java
- Selenium WebDriver
- Maven
- JUnit 5
- Log4j2
- Allure Report

## Running the Tests

```bash
mvn clean test
```

## Generate Allure Report

```bash
allure serve allure-results
```
